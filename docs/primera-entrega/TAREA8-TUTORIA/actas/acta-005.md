### Punto 5: Dudas sobre el formato de entrega

El equipo presentó las siguientes dudas al tutor:

**Pregunta de Carlos:** ¿Los wireframes HTML cuentan como prototipos funcionales o solo como diseños visuales para la primera entrega?
**Respuesta del tutor:** Para esta entrega cuentan como prototipos de interfaz. La funcionalidad backend se evaluará en la segunda entrega.

**Pregunta de María:** ¿El modelo E-R debe estar en formato imagen o puede entregarse como descripción textual con las tablas?
**Respuesta del tutor:** Preferentemente como imagen (diagrama), pero la descripción textual con las columnas de cada tabla es aceptable para la primera entrega.

**Pregunta de Luis:** ¿El script Bash debe ejecutarse en Linux real durante la presentación?
**Respuesta del tutor:** Sí, se demostrará en vivo en el servidor de prueba o en una máquina virtual durante la defensa.
