## Desarrollo de la reunión

### Punto 1: Presentación del proyecto

El tutor Prof. Méndez presentó el proyecto obligatorio del módulo: el **Sistema de Gestión Deportiva Modular (SGDM)**. Explicó los alcances generales:
- Plataforma web para gestión de torneos deportivos, mentales y electrónicos.
- Tecnologías obligatorias: PHP, MySQL, HTML, CSS, JavaScript, arquitectura MVC.
- Tres entregas distribuidas durante el año lectivo.
- La **Primera Entrega** comprende: análisis, diseño, documentación técnica, wireframes y estructura del frontend.

El tutor enfatizó que el proyecto debe ser funcional y demostrable en la tercera entrega.

### Punto 2: Nombre comercial del grupo

Se realizó una sesión de brainstorming donde cada integrante propuso nombres. Se presentaron y discutieron las opciones. Luego de debatir los criterios de selección (originalidad, profesionalismo, disponibilidad de dominio), el equipo votó. El resultado fue:

**Nombre elegido: Telyux Software Development**
- Votos a favor: 5/5
- Slogan propuesto: "Código que compite."
